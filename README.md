## Project Overview

The Madhav E-Commerce Sales Dashboard is an interactive data visualization project developed using Microsoft Power BI.

The dashboard provides a clear overview of e-commerce sales performance and helps analyze important business metrics such as sales amount, quantity, profit, average order value, customer performance, product categories, payment methods, states, sub-categories, and monthly profit trends.

The main objective of this project is to transform raw sales data into meaningful visual insights that can support business analysis and decision-making.


**Dashboard Preview**

### Project Objectives

Analyze overall e-commerce sales performance.

Monitor total sales amount and quantity.

Analyze total profit generated.

Understand average order value.

Compare sales performance across different states.

Analyze customer-wise sales.

Understand product category performance.

Analyze payment method usage.

Identify profitable and less profitable sub-categories.

Analyze monthly profit trends.

Create an interactive dashboard for business decision-making.

📊 Key KPIs



***The dashboard contains the following important Key Performance Indicators (KPIs):***

1. **Sales Amount**

Represents the total revenue generated from all sales transactions.

2. **Quantity**
Represents the total number of products sold.

3. **Profit**

Represents the total profit generated from the sales.

4. **Average Order Value (AOV)**

AOV represents the average value of an order.

A common formula is:

AOV = Total Sales Amount / Number of Orders
